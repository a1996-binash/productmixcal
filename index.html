Calculation Method
The calculator uses your customized original recipe as the ratio.

For example, if your recipe is:
A = 1.5 kg
B = 0.5 kg
C = 3 kg

If C is selected as the base:
A = C × (A Recipe ÷ C Recipe)
B = C × (B Recipe ÷ C Recipe)
